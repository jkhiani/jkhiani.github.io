# Cyber Detective

Web build of **Cyber Detective**, hosted on GitHub Pages.

Play: https://jkhiani.github.io/

Source project lives in `code-mystery-game` (Godot 4.4). Re-export with:

```bash
godot --headless --path /path/to/code-mystery-game --export-release Web build/web/index.html
```

Then copy `build/web/*` into this repository root.
